# AI2Doc v0.1.0

## 🎉 First Public Release

AI2Doc converts AI conversations into professional Word documents.

Supported input includes Markdown copied from:

- ChatGPT
- DeepSeek
- Claude
- Gemini
- Any Markdown-based AI output

## Features

### Document Generation

- Markdown to DOCX
- Professional templates
- Academic reports
- Business reports
- Learning notes

### Math Support

- LaTeX formulas
- Native Word OMML equations

### Web Application

- Paste an AI response or upload a Markdown file
- Select a document template
- Generate and download DOCX

### Deployment

- Docker Compose
- Local deployment

## Verification

Passed:

- Backend CI
- Frontend CI
- Docker Build
- Docker E2E
- Microsoft Word verification

## Quick Start

```bash
git clone https://github.com/Leo070506/AI2Doc.git
cd AI2Doc
docker compose up --build
```

Open [http://localhost:8080](http://localhost:8080).

## Current Limitations

- Docker images currently target `linux/amd64`.
- The MVP has no authentication, rate limiting, database, cloud storage or AI API dependency.
- Download state lives in one backend process; multi-worker deployment is unsupported.
- Formula support covers the tested common LaTeX subset, not arbitrary LaTeX packages.
- Do not expose the MVP directly to the public internet without a reverse proxy, rate limits and resource controls.
