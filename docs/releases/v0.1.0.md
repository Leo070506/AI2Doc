# AI2Doc v0.1.0

> Release draft — publish only after GitHub Actions and Docker end-to-end gates pass.

AI2Doc turns AI conversations into clean, editable professional Word documents. Paste an AI answer or upload Markdown, choose a document style, and download a DOCX generated by server-side Pandoc.

## Highlights

- Paste AI-generated Markdown or upload a `.md` / `.markdown` file.
- Generate editable DOCX with headings, lists, tables and Chinese text.
- Keep common LaTeX formulas as native Word math (OMML), not images.
- Choose Academic, Report or Notes document styles.
- Run the complete Web MVP with Docker Compose.
- Process files temporarily and delete each workspace after download.

## Quick start

```bash
git clone https://github.com/Leo070506/AI2Doc.git
cd AI2Doc
docker compose up --build
```

Open `http://localhost:8080`.

## Current limitations

- Docker images currently target `linux/amd64`.
- The MVP has no authentication, rate limiting, database or cloud storage.
- Download state lives in one backend process; multi-worker deployment is unsupported.
- Formula support covers the tested common LaTeX subset, not arbitrary LaTeX packages.
- Do not expose the MVP directly to the public internet without a reverse proxy, rate limits and resource controls.
