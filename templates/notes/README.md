# Notes template

面向学习笔记和密集参考资料的 Milestone 0 reference DOCX。

- 基础预设：`compact_reference_guide`
- 命名覆盖：`learning_notes accent`（标题使用克制的青绿色强调）
- 正文：Calibri 11 pt、1.25 倍行距、段后 6 pt
- 列表：紧凑缩进与段后 4 pt
- 页面：US Letter、四边 1 英寸页边距
- 页眉页脚：Learning Notes 标识与原生页码字段
- 表格：浅蓝灰表头、固定模板级宽度与单元格边距

`template.docx` 由 Pandoc 3.9.0.2 默认 reference DOCX 派生，仅用于技术验证。
