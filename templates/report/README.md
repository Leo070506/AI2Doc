# Report template

面向商业报告和管理简报的 Milestone 0 reference DOCX。

- 设计预设：`standard_business_brief`
- 正文：Calibri 11 pt、1.10 倍行距、段后 6 pt
- 标题层级：16/13/12 pt，商务蓝色层级
- 页面：US Letter、四边 1 英寸页边距
- 页眉页脚：Business Brief 标识与原生页码字段
- 表格：浅灰表头、固定模板级宽度与单元格边距

`template.docx` 由 Pandoc 3.9.0.2 默认 reference DOCX 派生，仅用于技术验证。
