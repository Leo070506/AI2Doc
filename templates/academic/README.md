# Academic template

面向学术论文和研究报告的 Milestone 0 reference DOCX。

- 基础预设：`narrative_proposal`
- 命名覆盖：`academic_typography`（Times New Roman；中文使用宋体）
- 正文：11 pt、两端对齐、1.333 倍行距、段后 8 pt
- 标题层级：16/13/12 pt，克制的蓝色层级
- 页面：US Letter、四边 1 英寸页边距
- 页眉页脚：研究文档标识与原生页码字段
- 表格：浅灰蓝表头、固定模板级宽度与单元格边距

`template.docx` 由 Pandoc 3.9.0.2 默认 reference DOCX 派生，仅用于技术验证。正式模板体系需在 Phase 2 增加版本、预览与兼容性元数据。
